Sobre o sistema

Este sistema foi elaborado como uma ferramenta experimental e educativa para apoiar a avaliação de competências profissionais, a organização dos resultados e o acompanhamento da evolução dos registros. A proposta é transformar as notas informadas pelo usuário em indicadores simples de média, percentual e classificação de perfil, permitindo também visualizar os resultados por meio de tabela e gráficos.

Como utilizar

  1. Cadastro: preencha nome, idade, formação, área, período e objetivos/observações.
  2. Competências: informe uma nota de 1 a 10 para cada competência.
  3. Salvar: grava o cadastro no navegador e calcula média, percentual e perfil.
  4. Base de Avaliações: mostra os registros salvos, média, percentual e classificação.
  5. Editar: carrega um cadastro para alteração e registra uma nova avaliação no histórico.
  6. Dashboard: apresenta gráficos das competências e da evolução histórica.
  7. Exportar Excel: gera uma planilha com os dados das avaliações.
  8. Backup JSON: cria uma cópia dos dados para posterior importação.
  9. Importar JSON: recupera um backup previamente salvo.
  10. Exportar PDF: gera o relatório completo do cadastro selecionado.
  11. Limpar Tudo: remove os registros do navegador. Faça backup antes.

Como interpretar os resultados

A média é calculada a partir das sete competências. O percentual corresponde à média convertida para uma escala de 0% a 100%. A classificação é:

  • P0 – Crítico: média até 2.
  • P1 – Ruim: acima de 2 até 3,5.
  • P2 – Instável: acima de 3,5 até 6.
  • P3 – Funcional: acima de 6 até 7,5.
  • P4 – Proficiente: acima de 7,5 até 9,5.
  • P5 – Excelente: acima de 9,5 até 10.

Motivação e caráter experimental

A elaboração desta aplicação tem finalidade experimental, acadêmica e educativa. Seu objetivo é demonstrar, de forma prática, conceitos de avaliação, cálculo de indicadores, armazenamento local, histórico, dashboard e geração de relatórios.

Os resultados são indicadores de apoio e aprendizagem e não devem ser interpretados, isoladamente, como diagnóstico definitivo ou decisão profissional automática.

Importante: este projeto é destinado a fins educativos e sem finalidade de lucro. Os dados são armazenados no localStorage do navegador, conforme a implementação atual. Recomenda-se realizar o backup JSON antes de limpar os dados ou mudar de ambiente.
